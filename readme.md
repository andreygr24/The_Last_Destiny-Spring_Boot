# The Last Destiny Guild - Spring Boot

Backend Project of my old Guild in World Of Warcraft, I recreated for learn
Java, MySQL adn Spring Boot.

## What it does

* Members List with rank and class
* Guild bank with items and discounts
* Apply form with validations
* Login with 3 attempts


## Tech

- Java
- MySQL
- Spring Boot

## How to run

```bash
mvn spring-boot:run

Open http://localhost:8080

Endpoints
GET /members - List members
GET /bank - List bank items
GET /apply - List applies
POST /apply - Send an apply
POST /login - Login (demo user)
